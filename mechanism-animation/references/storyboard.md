# 分镜：动手之前先写这张表

分镜是这类页面里最值钱的一步。画面和时间都能改，讲法错了要整页重排。

## 怎么写

先回答三个问题，写在表的上面：

1. **读者是谁、他已经知道什么、不关心什么？看完要明白哪一句话？**（「同一份数据不用每台虚机各存一份」）
2. **分几段讲？** 每段一个模块（2–4 个）。常用的分法：
   - 没问题的情况 → 出问题的情况 → 解法 → 进一步优化
   - 准备 → 运行 → 收尾
   - 方案 A → 方案 B（差别在过程里）
3. **图上固定有哪几样东西？**（宿主、虚机、磁盘、内存条……）它们在画布上各占哪一块，全程不换位置。
4. **颜色和动作各代表什么？** 列出来，全页不换用法。例：青 = 数据，紫 = 程序，橙 = 正在发生的动作；橙线画出来 = 发出请求，色块飞过去 = 数据送到，橙圈 = 共用的那一份，整组变淡 = 用不上了。
5. **说明文字放哪？** 两种位置：一步一句的结论，放在两排东西之间的空带上；细节和数字出处，放在画布一角固定的小注区（每步 2–4 行）。先把这两块地方留出来。

然后每步一行：

| # | id | 这一步讲的一件事（= 标题） | 画面上依次发生什么 | 这一步结束时：留着 / 变淡 / 清掉什么 | 左边一句话 | 要点（≤ 3） |
|---|---|---|---|---|---|---|

写「画面上依次发生什么」时用箭头串起来：`宿主出现 → 6 块数据从磁盘飞进宿主内存 → 虚机出现 → 数据复制进虚机 → 容器一个个出现 → 5 条箭头汇到同一份上（橙圈）`。写不成一串先后，说明这一步塞了不止一件事，或者因果没想清。

「结束时留着 / 变淡 / 清掉什么」是跨步骤的状态，写代码时最容易漏：请求箭头这一步结束就退场；数据块留到哪一步；「从头看」的那一步要清掉哪些、计数是否归零；哪些东西在后面用不上了要变淡。在分镜里定下来，别等写到一半临时决定。

## 过一遍检查

- [ ] 每一步只有一件事；标题是一句话，不是名词。
- [ ] 模块顺序是先易后难；问题出现之前，读者已经看过「正常的样子」。
- [ ] 每一步里，东西按先底层后上层、先因后果的顺序出现。
- [ ] 主线每一步都是**实际的做法**；默认值 / 别家做法 / 旧方案只出现在要点里。
- [ ] 相邻两步的画面有看得见的差别。
- [ ] 每一步结束时的画面单独看说得通；强调标记没有带进后面的步骤。
- [ ] 最后回答了「所以呢」：对读者意味着什么、现在做到哪了。
- [ ] 页面上没有内部名字（RFC / PR 号、文件名、函数名、机器名），除非读者就是这段代码的开发者。
- [ ] 每个数字都有出处，图上没有没交代过的数字或单位。
- [ ] 文字里没有引用后面才讲的内容。
- [ ] 步数：一个模块 2–4 步，全页 ≤ 12 步。再多就拆成两页。

## 例子：虚机内存那一页（12 步，定稿版）

一句话：程序跑在虚机里，读过的数据和用完的内存是怎么省下来的。
固定的东西：上半是虚机，下半是宿主（左：页缓存和磁盘；右：宿主内存占用条和小注）。

| # | 模块 | 讲的一件事 | 画面上依次发生什么 |
|---|---|---|---|
| 1 | 一台虚机里的容器 | 一台虚机里跑很多容器，读的是同一份 | 只有宿主 → 数据从磁盘进宿主内存 → 虚机出现 → 数据复制进虚机 → 容器一个个出现 → 读箭头汇到同一份（橙圈） |
| 2 | 〃 | 用完还回去：按 4 KB 报 | 虚机内存格子出现 → 两个容器退出 → 它们的页变空 → 小页飞到宿主占用条 → 那一段缩短 |
| 3 | 〃 | 冷缓存回收（还没做） | 缓存块变虚线 → 飞到占用条 → 缩短；标「试验做过 · 还没上线」 |
| 4 | 微虚机 · 问题 | 换成很多台虚机：每台各存一份 | 大虚机淡出、三个容器长成三台虚机 → 数据拷进每台 → 每台里才出现程序 → 占用条变长 |
| 5 | 〃 | 用完也不还 | 虚机里一段变灰（已释放）→ 宿主占用条不变 |
| 6 | 微虚机 · 解法 | 把层文件映射进虚机 | 宿主缓存清空（「从头看」）→ 磁盘上的文件被圈出 → 每台虚机出现一段映射区 → 虚线连到同一个文件 |
| 7 | 〃 | 读文件直接落到宿主那一份 | 三台各读几页（有重叠）→ 读到的页才从磁盘进宿主内存 → 重叠的页被圈出 |
| 8 | 〃 | 代价 | 每台多出一小段元数据；磁盘文件标「不压缩、对齐」 |
| 9 | 微虚机 · 优化 | 把一台虚机的内存放大看 | 另两台滑出 → 虚机 1 放大成 8 格，在用 / 缓存 / 空闲混在一起 |
| 10 | 〃 | 抽样找出冷页 | 橙点在格子里跳 → 格子按冷热上色（蓝冷红热） |
| 11 | 〃 | 回收冷页缓存 | 蓝的部分变浅灰（空了，宿主还占着） |
| 12 | 〃 | 空闲页还给宿主 | 每格空的部分飞到宿主占用条对应的段 → 那一段缩没 |

这张表改过三次大的：最初容器排在最后（读者以为容器和虚机有同样的问题）；「按 2 MB 报」原来是单独一步（读者以为实际分两阶段）；第 1 步原来所有框一开场就在（顺序不对）。三次都是讲法问题，都本该在分镜阶段发现。
